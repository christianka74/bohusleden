BOHUSLEDEN PWA

Lägg upp alla fyra filer på samma HTTPS-webbadress:
index.html
manifest.webmanifest
sw.js
asdacp.jpg

På iPhone:
1. Öppna adressen i Safari.
2. Tryck Dela.
3. Välj Lägg till på hemskärmen.
4. Starta appen från hemskärmen.

Efter första besöket kan appen fungera offline.
Etapper och datum sparas lokalt.

Viktigt: en PWA/service worker kan inte installeras från en lokal file://-adress i Filer. HTTPS krävs.
